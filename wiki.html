Documentation technique, architecture et accès.

1. Architecture du Projet

Le projet ???? Solutions de mobilité Saint-Malo est composé de deux entités distinctes hébergées sur le même serveur :

  • Site Vitrine (Dossier /wordpress) :
    • Propulsé par le CMS WordPress.
    • Thème adapté pour la présentation de l'entreprise.
    • Module spécifique développé par l'équipe pour l'affichage dynamique des "Partenaires".

  • Intranet (Dossier /intranet) :
    • Développé "From Scratch" en PHP 7.4+.
    • Interface utilisant le framework Bootstrap 5.
    • Données : Aucune base de données MySQL n'est utilisée. Le stockage se fait via :
      • Fichiers .json pour les utilisateurs et la configuration.
      • Fichiers .csv pour les annuaires (clients, partenaires).
      • Fichiers .txt pour les documents partagés.

2. Fonctionnalités et Utilisation

Partie Vitrine (Publique)

  • Consultation : Pages "Accueil", "Qui sommes-nous", "Histoire" et "Activités".
  • Partenaires : Visualisation des partenaires via un plugin personnalisé (données synchronisées avec l'intranet).

Partie Intranet (Privée)

  • Authentification : Système de login sécurisé par lecture de fichiers JSON.
  • Gestion des fichiers : Upload, visualisation et suppression de fichiers (.txt, .csv) partagés entre collaborateurs.
  • Annuaires (CRUD) :
    • Gestion des employés (12 pers. min) : Ajout/Modif/Suppr de profils avec photo.
    • Gestion des clients (30 pers. min) : Liste, détails et téléchargement de fiches.
    • Gestion des partenaires (5 min) : Les modifications ici se répercutent sur la Vitrine.
